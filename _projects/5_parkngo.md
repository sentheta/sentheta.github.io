### ParkNGo (2024)

Developed as part of the **NTU SC2006 Software Engineering** coursework, ParkNGo is a comprehensive full-stack web application designed for real-time car park discovery, availability tracking, and parking management across Singapore.

#### Key Features & Contributions
- **Real-time Search & Filtering:** Allows drivers to search, sort, and filter car parks based on location proximity, pricing rates, and live vehicle space availability.
- **Geolocation Integration:** Interactive map interface displaying dynamic routing and nearby carpark status using live government open data APIs.
- **Full-Stack Architecture:** Built using **React.js**, **Next.js**, and **TailwindCSS**, following modular software design patterns and robust testing practices.
