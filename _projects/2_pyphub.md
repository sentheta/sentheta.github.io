### PYPHub (2025)

**PYPHub** is a web forum developed for academic past-year-paper (PYP) discussions and automated solution generation, created as an initiative for the **NTU Students' Computing and Data Science Club**.

#### Key Features & Contributions
- **Student Discussion Forum:** Provides a dedicated platform for NTU students to discuss coursework problems, past examination papers, and collaborative solution drafting.
- **Automated Solution Pipeline:** Engineered a complete data ingestion pipeline that preprocesses and uploads exam papers and course materials to **AWS S3** and **OpenAI vector stores**.
- **Enhanced LLM Retrieval:** Significantly improves contextual grounding and resource accessibility for both human users and LLM agents during solution generation.
- **Tech Stack:** Python, AWS S3, Vector Stores, OpenAI API, Next.js, Node.js.
