### NTU Final Year Project (2026 – Present)

This project focuses on research in **Explainable AI (XAI)** methods and **neuro-fuzzy architectures**, conducted as part of the Final Year Project at **Nanyang Technological University (NTU)**.

#### Overview
- Investigating interpretable deep neural network architectures that combine neural learning with rule-based fuzzy reasoning systems.
- Designing mechanisms for dynamic, evolving network topologies that adapt structure based on incoming data streams while maintaining transparent decision boundaries.
- Evaluating model performance on benchmark datasets against conventional deep learning approaches, demonstrating enhanced interpretability without sacrificing predictive accuracy.
