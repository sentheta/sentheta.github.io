### NTU AIML Club Official Website (2025)

The official website for the **NTU Artificial Intelligence and Machine Learning Club**, created to showcase club initiatives, workshops, hackathons, and technical publications.

#### Key Features & Contributions
- Designed and built a modern, responsive web application using **React.js**, **TypeScript**, and **TailwindCSS**.
- Leveraged open-source component libraries and contemporary design systems to deliver an intuitive user experience and accessible navigation.
- Integrated automated CI/CD deployment pipelines for streamlined content updates.
